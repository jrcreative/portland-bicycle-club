*** WooCommerce Box Office Changelog ***

= 1.6.2 - 2026-10-07 =
* Fix - Tickets block's "Order tickets by" setting was not actually sorting results; ticket scan form validation could fail to initialize on some sites.
* Fix - Keep tickets aligned with order trash, restoration and deletion in legacy storage and HPOS while preserving prior ticket revocations.
* Fix - Bulk ticket actions now require permission to edit each ticket; custom staff roles with only edit_posts must be updated before use.
* Fix - Generate checkout ticket barcodes from validated current-order mappings while preserving existing codes and valid tickets alongside incomplete mappings.
* Fix - Preserve free tickets until their full order-line quantity is refunded.
* Fix - Revoked all tickets on fully refunded order lines containing more than five tickets.
* Fix - Required active paid tickets for private content and respected printing settings on direct print links.
* Fix - Restricted ticket and queued-email administration to commerce roles.
* Fix - Bound ticket-field allocation when using customer details.
* Fix - Custom ticket description renderers must register through woocommerce_box_office_ticket_description_formatters; built-in formats retain their layouts.
* Fix - Require scanner authorization before barcode lookup and scope scan nonces to authorized forms, preserving explicit guest scanner policies.
* Fix - Kept manually created tickets pending while their new corresponding order awaits payment.
* Fix - Use cryptographic randomness for new ticket admission barcodes.
* Fix - Kept attendee field text literal while preserving printable-ticket shortcode arguments.
* Fix - Keep private-content recovery responses neutral for all valid email addresses.
* Fix - Limit repeated private-content recovery emails to each recipient.
* Fix - Keep private-content recovery bound to the current public page, including archive forms.
* Fix - Show an unavailable notice when scanning tickets without Order Barcodes active.
* Fix - Made the ticket token hint on the product ticket panel translatable.
* Tweak - Declared compatibility with WooCommerce 11.2.
* Dev - Switched the version headings in changelog.txt to the WordPress.org format.
* Dev - Updated dependencies to address security advisories.
* Dev - Enforce checks for authored stylesheets.
* Dev - Run PHPCS and QIT tooling on PHP 8.4.
* Dev - Read pull request metadata as data and limited the issue-linking workflow token permissions.
* Dev - Managed changelog entries with the Jetpack Changelogger, so pull requests add a change file instead of writing the entry in the pull request description.
* Dev - Updated the development toolchain to Node 24.18 and @wordpress/scripts 35.
* Dev - Updated development dependencies to address security advisories.
